# Shorts Automation Control Tower

숏츠 제작 6단계(대본 → 음성 → 이미지 → 영상화 → 모션그래픽 → 최종 렌더링)를 단계별로 점검하는 관제 화면입니다.
HTML, CSS, JavaScript만 사용하며 유료 API나 서버가 필요 없습니다.

## 화면 구성

| 영역 | 내용 |
|---|---|
| 왼쪽 · PROJECT TREE | 숏츠 작업 폴더의 파일 구조, 파일 선택 시 설명과 연결 단계, 연결 상태, 작업 폴더 확인 |
| 가운데 · 전체 파이프라인 | 6단계 흐름도. 단계를 누르면 상세 검수 창이 열립니다. |
| 오른쪽 · 단계별 상세 검수 | 단계 카드. 진행 상태, 체크 진행률, 파일 경로 상태, 세부보기 버튼 |

- PC(1024px 이상)에서는 3개 영역이 나란히 보이고, 선택한 단계가 가운데와 오른쪽 카드를 점선으로 잇습니다.
- 휴대폰(1023px 이하)에서는 한 줄로 자동 재배치됩니다.

## 상태 표시 기준

- **대기 / 진행 중 / 완료**: 체크리스트 항목을 직접 체크한 개수로 정합니다. 모두 체크하면 "완료"입니다.
- **파일 상태**
  - `미확인`: 작업 폴더를 선택하지 않았습니다. 이 화면은 파일을 직접 열어 볼 수 없습니다.
  - `확인됨`: 선택한 폴더 안에서 같은 경로의 파일 이름을 찾았습니다. 파일 내용은 읽지 않습니다.
  - `없음`: 선택한 폴더에서 해당 경로의 파일을 찾지 못했습니다.
- **연결 상태**: Google Flow와 CapCut은 이 화면에서 호출하지 않으므로 항상 "미연결"로 표시합니다.

## 실행 방법

### PC에서 실행

1. ZIP 파일을 풉니다.
2. `shorts-control-tower/index.html`을 브라우저(Chrome, Edge 등)로 엽니다.

이 방법은 화면과 체크 기능을 바로 쓸 수 있습니다. 다만 오프라인 실행과 앱 설치는 동작하지 않고, 상단에 안내 메시지가 표시됩니다.

### 오프라인 실행과 앱 설치 (HTTPS 또는 localhost 필요)

서비스 워커와 앱 설치 기능은 **HTTPS 주소** 또는 **localhost**에서만 동작합니다. 브라우저는 `file://` 주소나 일반 HTTP 주소에서 서비스 워커를 등록하지 않습니다.

- **PC에서 테스트**: `shorts-control-tower` 폴더에서 아래 명령 중 하나를 실행한 뒤 `http://localhost:8080`을 엽니다.
  ```bash
  python3 -m http.server 8080
  ```
- **휴대폰에서 사용**: `shorts-control-tower` 폴더 전체를 HTTPS를 지원하는 정적 호스팅 서비스에 올립니다. 폴더 구조는 그대로 두세요. 업로드 후 주소를 Android Chrome에서 열면 메뉴의 "홈 화면에 추가" 또는 "앱 설치"를 선택할 수 있습니다.
- 한 번 열린 뒤에는 인터넷이 없어도 같은 주소로 화면을 열 수 있습니다. 파일을 수정하면 `sw.js`의 `CACHE_NAME` 버전을 올려야 변경 내용이 적용됩니다.

### 휴대폰에서 같은 Wi-Fi의 PC 주소로 열기

PC에서 `python3 -m http.server 8080 --bind 0.0.0.0`을 실행하면 `http://PC의-IP:8080`으로 화면은 열립니다. 다만 이 주소는 HTTPS가 아니므로 오프라인 실행과 앱 설치는 동작하지 않습니다.

## 작업 폴더 확인 방법

1. 왼쪽의 **작업 폴더 선택** 버튼을 누릅니다.
2. 숏츠 작업 폴더를 고릅니다. 폴더 안에 아래 경로가 있으면 `확인됨`으로 바뀝니다.

```
숏츠 작업 폴더/
├─ SKILL.md
├─ tone-rules.md
├─ files/
│  ├─ INDEX.md
│  ├─ scene-plan.md
│  ├─ audio-sync.md
│  ├─ image-review.md
│  ├─ video-review.md
│  ├─ motion-edit.md
│  └─ render-check.md
└─ examples/
   └─ good-output.md
```

- 폴더 선택은 PC의 Chrome, Edge 같은 데스크톱 브라우저에서 가장 안정적으로 동작합니다. 휴대폰 브라우저가 폴더 선택을 지원하지 않으면 파일 경로는 계속 `미확인`으로 표시됩니다.
- 폴더 선택 후 새로고침하면 폴더 정보가 사라집니다. 필요하면 다시 선택하세요.

## 체크 상태 저장

- 체크 상태는 **이 브라우저에만** 저장됩니다(localStorage). 다른 기기나 다른 사람과 공유되지 않습니다.
- 브라우저의 사이트 데이터를 지우거나 비공개 창을 닫으면 체크 상태가 사라집니다.

## 한계

- 이 앱은 Google Flow, CapCut, 음성·이미지 생성 도구에 연결하지 않습니다. 결과물을 자동으로 검사하지도 않습니다.
- 체크리스트는 사용자가 직접 확인한 내용만 반영합니다. "완료"는 체크 결과이며, 파일 확인이 함께 끝났다는 뜻은 아닙니다.
- 작업 폴더 확인은 파일 이름과 경로만 비교합니다. 파일의 내용이나 영상 품질은 확인하지 않습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 구조 |
| `styles.css` | 디자인과 화면 크기별 배치 |
| `app.js` | 단계, 체크리스트, 파일 확인, 상세 창 동작 |
| `manifest.json` | 앱 설치 정보(이름, 아이콘, 실행 방식) |
| `sw.js` | 오프라인 실행을 위한 파일 캐시 |
| `icon.svg`, `icon-192.png`, `icon-512.png` | 앱 아이콘 |
| `README.md` | 사용 설명서 |

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 상단에 "파일로 직접 열었습니다" 안내가 보임 | 정상입니다. 오프라인 실행과 앱 설치가 필요하면 HTTPS 주소나 localhost로 여세요. |
| 오프라인 기능 등록 실패 안내 | `sw.js`가 `index.html`과 같은 폴더에 있는지, HTTPS 주소로 열었는지 확인하세요. |
| 체크 상태가 새로고침 후 사라짐 | 비공개 창인지, 사이트 데이터 저장이 차단되었는지 확인하세요. |
| 화면이 깨짐 | 브라우저를 새로고침하세요. 계속되면 Console(F12)의 오류 메시지를 확인하세요. |
| 파일 상태가 계속 `미확인` | 작업 폴더를 선택했는지, 브라우저가 폴더 선택을 지원하는지 확인하세요. |
